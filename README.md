# java-calculator-precourse
## 계산 기능
- [x] 주어진 숫자 리스트의 합을 구하는 기능

## 파싱 기능
- [ ] 쉼표(,)와 콜론(:)을 기본 구분자로 문자열을 분리해 숫자 리스트로 만드는 기능
- [ ] 커스텀 구분자를 분리하고, 나머지 문자열을 숫자 리스트로 만드는 기능

## 에러 처리
- [ ] 분리된 문자가 숫자가 아닐 경우 예외 처리
- [ ] 입력값에 음수가 포함된 경우 예외 처리

## 입출력
- [ ] 사용자에게 안내 문구를 출력하고 문자열을 입력받는 기능
- [ ] 최종 계산 결과를 형식에 맞게 출력하는 기능
